Developer Preview 2, on 22 November 2016, was the last preview before
Android 7.1.1. Google called it "a release candidate for Android 7.1.1", with
"near-final system behaviors and UI" and the latest bug fixes.

|              |                                                                                      |
| ------------ | ------------------------------------------------------------------------------------ |
| Release date | 22 November 2016                                                                     |
| Build        | `NPF26F`; `NPF26H` on the Pixel C                                                    |
| Devices      | Nexus 5X, Nexus 6P, Nexus 9 and Pixel C                                              |
| API status   | Unchanged: the API 25 features "already introduced in Developer Preview 1"           |
| Tools        | Updated SDK build and platform tools, API 25 emulator images, support library 25.0.1 |

The Nexus 9 was the new device. Google had said in October that the preview
would reach "other supported devices" by its end, and Android Police reported
that Google's preview timeline had listed the Nexus 6 and Nexus Player for
this build. Both were dropped from it, though they still got the final 7.1.1.
The Pixel and Pixel XL were not in the beta program and waited for the final
release.

The Nexus 9 images were missing at first and appeared later that day, Android
Police reported. Google offered factory images for this build but no OTA
links, per 9to5Google; enrolled devices still received it over the air.
Google's plan was unchanged: 7.1.1 for every supported device in early
December, with the source pushed to AOSP at the same time.
