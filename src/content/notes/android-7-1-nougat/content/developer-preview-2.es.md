La Developer Preview 2, del 22 de noviembre de 2016, fue la última preview
antes de Android 7.1.1. Google la llamó "a release candidate for Android
7.1.1", con "near-final system behaviors and UI" y las últimas correcciones.

|                  |                                                                                          |
| ---------------- | ---------------------------------------------------------------------------------------- |
| Fecha            | 22 de noviembre de 2016                                                                  |
| Build            | `NPF26F`; `NPF26H` en el Pixel C                                                         |
| Dispositivos     | Nexus 5X, Nexus 6P, Nexus 9 y Pixel C                                                    |
| Estado de la API | Sin cambios: las funciones de la API 25 "already introduced in Developer Preview 1"      |
| Herramientas     | Build tools y platform tools nuevas, imágenes de emulador API 25, support library 25.0.1 |

El Nexus 9 fue el dispositivo nuevo. En octubre Google había dicho que la
preview llegaría a "other supported devices" antes de terminar, y Android
Police informó que el calendario de la preview de Google incluía el Nexus 6 y
el Nexus Player en esta build. Ambos quedaron fuera, aunque recibieron la
versión final de 7.1.1. El Pixel y el Pixel XL no estaban en el programa beta
y esperaron a la versión final.

Las imágenes del Nexus 9 faltaban al principio y aparecieron más tarde ese
día, según Android Police. Google publicó imágenes de fábrica de esta build
pero no enlaces OTA, según 9to5Google; los dispositivos inscritos la recibieron
igual por OTA. El plan de Google no cambió: 7.1.1 para todos los dispositivos
compatibles a principios de diciembre, con el código subido a AOSP al mismo
tiempo.
