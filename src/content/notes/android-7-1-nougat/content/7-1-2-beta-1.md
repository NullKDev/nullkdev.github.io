On 30 January 2017 Google opened a public beta of Android 7.1.2 through the
Android Beta Program. Google described 7.1.2 as "an incremental maintenance
release focused on refinements": bug fixes, optimizations and "a small number
of enhancements for carriers and users". It stayed at API 25, with no new
developer APIs.

|              |                                                                             |
| ------------ | --------------------------------------------------------------------------- |
| Release date | 30 January 2017                                                             |
| Build        | `NPG05D`; `NPG05E` on the Pixel and Pixel XL                                |
| Devices      | Pixel, Pixel XL, Nexus 5X, Nexus Player and Pixel C                         |
| Status       | Compatibility Test Suite (CTS) approved, so apps such as Android Pay worked |

The Nexus 6P was not in this build. Google said it was "preparing an update
for Nexus 6P that we expect to release soon". The Nexus 6 and Nexus 9 were not
on the list for the beta or for the final release, and 9to5Google noted this
was the first release to skip the Nexus 6.

Google's release notes listed known issues: Quick Settings could disappear on
the Pixel C, the Pixel Launcher could crash when searching with a physical
keyboard attached, and some UI hangs and Wi-Fi instability. 9to5Google later
reported that this build brought the Pixel's fingerprint swipe for
notifications to the Nexus 5X. Google promised the final release "in just a
couple of months".
