Developer Preview 5, build `NPD90G`, came out on 18 July 2016, "the last
milestone of this preview series". It is the first preview Google's blog
announced under the name Android 7.0 Nougat. It added no APIs: those had been
final since Preview 4. It brought near-final system images and an emulator
for final testing, plus bug fixes in the system and preinstalled apps.

CTS approval now included the Nexus 9, besides the 5X, 6, 6P and Pixel C.
Google's release notes list the Nexus 5X, 6, 6P, 9, Nexus Player, Pixel C and
General Mobile 4G; the Sony Xperia Z3, which had Previews 3 and 4, is not on
the list. Google asked developers to test the Nougat behaviour changes (Doze
on the go, background optimizations, screen zoom, permissions) and publish
their API 24 updates. The public rollout began five weeks later, on
22 August.
