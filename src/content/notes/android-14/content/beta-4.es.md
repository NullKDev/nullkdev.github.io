La Beta 4 salió el 11 de julio de 2023, la segunda build con estabilidad de
plataforma. Google dijo que ya se podían publicar en Google Play apps para
dispositivos con Android 14 en el nivel de API oficial.

|                       |                                                                    |
| --------------------- | ------------------------------------------------------------------ |
| Fecha                 | 11 de julio de 2023; Beta 4.1 el 26 de julio de 2023               |
| Build                 | `UPB4.230623.005`; 4.1 `UPB4.230623.007`                           |
| Parche de seguridad   | Julio de 2023                                                      |
| Dispositivos          | Del Pixel 4a (5G) al Pixel 7a, más el Pixel Tablet y el Pixel Fold |
| Cómo se obtenía       | Por OTA con Android Beta, o flasheando                             |
| Estabilidad de la API | Sí                                                                 |

El post no sumó funciones. Llevó la beta a la tablet y al plegable de Google, y
señaló el Android SDK Upgrade Assistant de Android Studio Hedgehog, que lista
los cambios de Android 14 que afectan a una app.

La Beta 4.1 corrigió apps que no volvían a abrirse tras cerrarlas con atrás
hasta reiniciar, un overscroll de `ScrollView` trabado después de un fling, las
llamadas por Wi-Fi y el ícono que entrega
`SplashScreen.setOnExitAnimationListener()`.
