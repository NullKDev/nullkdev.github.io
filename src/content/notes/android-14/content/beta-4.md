Beta 4 came out on 11 July 2023, the second build with platform stability.
Google said developers could now publish apps on Google Play for devices
running Android 14 at the official API level.

|                    |                                                                 |
| ------------------ | --------------------------------------------------------------- |
| Release date       | 11 July 2023; Beta 4.1 on 26 July 2023                          |
| Build              | `UPB4.230623.005`; 4.1 `UPB4.230623.007`                        |
| Security patch     | July 2023                                                       |
| Devices            | Pixel 4a (5G) to Pixel 7a, plus the Pixel Tablet and Pixel Fold |
| How to get it      | Over the air through Android Beta, or by flashing               |
| Platform stability | Yes                                                             |

The post added no features. It brought the beta to Google's tablet and
foldable, and pointed to the Android SDK Upgrade Assistant in Android Studio
Hedgehog, which lists the Android 14 changes that apply to an app.

Beta 4.1 fixed apps that could not relaunch after closing them with back until
a restart, a stuck `ScrollView` overscroll after a fling, Wi-Fi calling, and
the icon handed over by `SplashScreen.setOnExitAnimationListener()`.
