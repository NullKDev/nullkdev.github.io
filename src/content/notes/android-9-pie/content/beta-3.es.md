La Beta 3 salió el 2 de julio de 2018. Google la llamó "an early release
candidate build of Android with near-final system behaviors", sobre el nivel
de API 28 que la Beta 2 había congelado. AOSP la etiqueta como
`android-p-preview-4`.

|                       |                                                                                     |
| --------------------- | ----------------------------------------------------------------------------------- |
| Fecha                 | 2 de julio de 2018                                                                  |
| Build                 | `PPP4.180612.004`, según 9to5Google                                                 |
| Dispositivos          | Pixel, Pixel XL, Pixel 2 y Pixel 2 XL; Android Emulator; luego, teléfonos de socios |
| Cómo se obtenía       | Por aire con Android Beta, o flasheando la imagen de fábrica                        |
| Estabilidad de la API | Sí, desde la Beta 2                                                                 |

La build no agregó API. Trajo correcciones de errores, las actualizaciones de
seguridad de julio de 2018 y una actualización de las build tools de Android
Studio que publicó D8 como herramienta independiente. Google pidió probar las
apps con los App Standby buckets, las restricciones de privacidad y los
límites non-SDK.
