Beta 3 came out on 2 July 2018. Google called it "an early release
candidate build of Android with near-final system behaviors" on the API
level 28 that Beta 2 had frozen. AOSP tags it `android-p-preview-4`.

|                    |                                                                                 |
| ------------------ | ------------------------------------------------------------------------------- |
| Release date       | 2 July 2018                                                                     |
| Build              | `PPP4.180612.004`, as reported by 9to5Google                                    |
| Devices            | Pixel, Pixel XL, Pixel 2 and Pixel 2 XL; Android Emulator; partner phones later |
| How to get it      | Over the air through Android Beta, or by flashing the factory image             |
| Platform stability | Yes, since Beta 2                                                               |

The build added no APIs. It carried bug fixes, the July 2018 security
updates, and an Android Studio build-tools update that shipped D8 as an
independent tool. Google asked developers to test against App Standby
buckets, the privacy restrictions and the non-SDK limits.
