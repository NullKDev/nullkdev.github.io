Beta 4 came out on 25 July 2018, twelve days before the final release.
Google called it "the last preview milestone before we launch the official
Android P platform". AOSP tags it `android-p-preview-5`.

|                    |                                                                                  |
| ------------------ | -------------------------------------------------------------------------------- |
| Release date       | 25 July 2018                                                                     |
| Build              | `PPP5.180610.010`, as reported by 9to5Google                                     |
| Devices            | Pixel, Pixel XL, Pixel 2 and Pixel 2 XL; partner phones over the following weeks |
| How to get it      | Over the air through Android Beta, or by flashing the system image               |
| Platform stability | Yes, since Beta 2                                                                |

It was "a release candidate build with final system behaviors". Google asked
developers to finish compatibility testing, watch for non-SDK interface
use, and publish updates without changing their target level first.
Android 9 Pie shipped on 6 August 2018.
