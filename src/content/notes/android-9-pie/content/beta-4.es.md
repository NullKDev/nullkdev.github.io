La Beta 4 salió el 25 de julio de 2018, doce días antes de la versión final.
Google la llamó "the last preview milestone before we launch the official
Android P platform". AOSP la etiqueta como `android-p-preview-5`.

|                       |                                                                                          |
| --------------------- | ---------------------------------------------------------------------------------------- |
| Fecha                 | 25 de julio de 2018                                                                      |
| Build                 | `PPP5.180610.010`, según 9to5Google                                                      |
| Dispositivos          | Pixel, Pixel XL, Pixel 2 y Pixel 2 XL; los teléfonos de socios en las semanas siguientes |
| Cómo se obtenía       | Por aire con Android Beta, o flasheando la imagen del sistema                            |
| Estabilidad de la API | Sí, desde la Beta 2                                                                      |

Fue "a release candidate build with final system behaviors". Google pidió
terminar las pruebas de compatibilidad, revisar el uso de interfaces non-SDK
y publicar actualizaciones sin cambiar antes el nivel de target. Android 9
Pie salió el 6 de agosto de 2018.
