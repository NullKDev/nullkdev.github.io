Beta 3 came out on 9 February 2022 and was the last 12L beta. It was the first
12L build for the Pixel 6 and 6 Pro. Like Beta 2, it has no blog post; the
date and build come from Google's 12L release notes.

|                |                                                            |
| -------------- | ---------------------------------------------------------- |
| Release date   | 9 February 2022                                            |
| Build          | `S2B3.220205.007.A1`                                       |
| Security patch | February 2022                                              |
| Devices        | Pixel 3a, 4, 4a, 5, 5a and 6 series; Android Emulator; GSI |

Google listed three fixes: weather missing from the At a glance widget, a
screen-off animation that did not always play, and launcher crashes when
entering split screen with "Pin to Top".

Pixel 6 phones that took the newer February update, `SQ1D.220205.004`, could
not install Beta 3. 9to5Google quoted Google saying those phones would get
"the next upcoming beta build release in March" instead. Google's release
notes do not list a March build, so this note does not count one as a
milestone. The final release followed on 7 March 2022.
