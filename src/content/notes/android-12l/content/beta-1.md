Beta 1 came out on 8 December 2021. It was the first 12L build for phones and
the first with final APIs. Google "finalized the APIs early": its preview
timeline had planned final APIs for Beta 2.

|                    |                                                                        |
| ------------------ | ---------------------------------------------------------------------- |
| Release date       | 8 December 2021                                                        |
| Build              | `S2B1.211112.006`                                                      |
| Security patch     | December 2021                                                          |
| Devices            | Pixel 3a, 4, 4a, 4a (5G), 5 and 5a over the air; Android Emulator; GSI |
| Platform stability | Yes; the official API 32 SDK, with an API diff from `Sv2` DP1 to 32    |

Pixel owners got it by enrolling in Android Beta, and phones still enrolled
in the Android 12 Beta received it automatically. The Pixel 6 and 6 Pro were
listed as "coming soon". On a phone the large-screen features do not appear,
but the build carried the December security patch and the bug fixes.

With API 32 final, developers could compile against the official SDK. Google
asked them to watch feedback from Beta users and release compatible updates
without changing the app's target. Lenovo was still offering Developer
Preview 1 for the Tab P12 Pro, with updates "in the weeks ahead".
