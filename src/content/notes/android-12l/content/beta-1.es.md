La Beta 1 salió el 8 de diciembre de 2021. Fue la primera build de 12L para
teléfonos y la primera con las API finales. Google dijo que "finalized the
APIs early": su calendario de la preview las tenía previstas para la Beta 2.

|                       |                                                                       |
| --------------------- | --------------------------------------------------------------------- |
| Fecha                 | 8 de diciembre de 2021                                                |
| Build                 | `S2B1.211112.006`                                                     |
| Parche de seguridad   | Diciembre de 2021                                                     |
| Dispositivos          | Pixel 3a, 4, 4a, 4a (5G), 5 y 5a por OTA; Android Emulator; GSI       |
| Estabilidad de la API | Sí; el SDK oficial de la API 32, con un diff de API de `Sv2` DP1 a 32 |

Los dueños de un Pixel la recibían al inscribirse en Android Beta, y los
teléfonos que seguían en la beta de Android 12 la recibieron solos. Los Pixel 6
y 6 Pro figuraban como "coming soon". En un teléfono no aparecen las funciones
para pantallas grandes, pero la build traía el parche de seguridad de
diciembre y las correcciones de errores.

Con la API 32 final, los desarrolladores podían compilar contra el SDK
oficial. Google pidió atender los comentarios de los usuarios de la beta y
publicar actualizaciones compatibles sin cambiar el target de la app. Lenovo
todavía ofrecía la Developer Preview 1 para la Tab P12 Pro, con
actualizaciones "in the weeks ahead".
