Developer Preview 4 came out on 24 July 2017, four weeks before the final
release. Google called it "a release candidate build of Android O" and "the
final preview before we launch the official Android O platform to
consumers".

|                    |                                                                         |
| ------------------ | ----------------------------------------------------------------------- |
| Release date       | 24 July 2017                                                            |
| Build              | `OPP4.170623.014`                                                       |
| Devices            | Nexus 5X, Nexus 6P, Nexus Player, Pixel, Pixel XL and Pixel C; emulator |
| How to get it      | Over the air through Android Beta, or by flashing the factory image     |
| Platform stability | Yes, since Preview 3                                                    |

The build added no APIs. It brought "the final system behaviors, the latest
bug fixes and optimizations", on the API level 26 that had been final since
Preview 3. Support Library 26.0.0 went stable the same day, and Google
announced a new Android Testing Support Library with Android Test
Orchestrator and multiprocess Espresso.

Google asked developers to finish testing and publish updates at their
current target level, checking background location limits, notification
channels, and the networking, security and identifier changes. Android 8.0
Oreo shipped on 21 August 2017.
