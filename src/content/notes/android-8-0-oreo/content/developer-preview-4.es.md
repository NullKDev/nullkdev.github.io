La Developer Preview 4 salió el 24 de julio de 2017, cuatro semanas antes de
la versión final. Google la llamó "a release candidate build of Android O" y
"the final preview before we launch the official Android O platform to
consumers".

|                       |                                                                       |
| --------------------- | --------------------------------------------------------------------- |
| Fecha                 | 24 de julio de 2017                                                   |
| Build                 | `OPP4.170623.014`                                                     |
| Dispositivos          | Nexus 5X, Nexus 6P, Nexus Player, Pixel, Pixel XL y Pixel C; emulador |
| Cómo se obtenía       | Por OTA con Android Beta, o flasheando la imagen de fábrica           |
| Estabilidad de la API | Sí, desde la Preview 3                                                |

La build no sumó API. Trajo "the final system behaviors, the latest bug
fixes and optimizations", sobre el nivel de API 26 que era final desde la
Preview 3. La Support Library 26.0.0 pasó a estable ese mismo día, y Google
anunció una nueva Android Testing Support Library con Android Test
Orchestrator y Espresso multiproceso.

Google pidió terminar las pruebas y publicar actualizaciones con el target
actual, revisando los límites de ubicación en segundo plano, los canales de
notificación y los cambios de red, seguridad e identificadores. Android 8.0
Oreo salió el 21 de agosto de 2017.
