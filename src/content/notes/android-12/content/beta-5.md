Beta 5 came out on 8 September 2021, four weeks after Beta 4. Google
described it as "a release candidate build of Android 12" and the final beta
update before the official release.

|                    |                                                                        |
| ------------------ | ---------------------------------------------------------------------- |
| Release date       | 8 September 2021                                                       |
| Build              | `SPB5.210812.002`                                                      |
| Security patch     | August 2021                                                            |
| Devices            | Pixel 3, 3a, 4, 4a, 5 and 5a; partner phones such as Sharp; Android TV |
| How to get it      | Over the air through Android Beta, or by flashing                      |
| Platform stability | Yes, since Beta 4                                                      |

The build added no APIs, only fixes and optimizations on the surfaces frozen
at Beta 4. The Pixel 5a with 5G joined the supported devices. Google pointed
developers to new lint checks in Android Studio Arctic Fox for custom splash
screens, coarse location requested with fine location, media formats and
the high sensor sampling rate permission.

Google pushed the source to AOSP on 4 October 2021, and the Pixel rollout
started on 19 October.
