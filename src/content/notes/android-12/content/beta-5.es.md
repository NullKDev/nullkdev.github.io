La Beta 5 salió el 8 de septiembre de 2021, cuatro semanas después de la
Beta 4. Google la describió como "a release candidate build of Android 12" y
la última actualización beta antes de la versión oficial.

|                       |                                                                        |
| --------------------- | ---------------------------------------------------------------------- |
| Fecha                 | 8 de septiembre de 2021                                                |
| Build                 | `SPB5.210812.002`                                                      |
| Parche de seguridad   | Agosto de 2021                                                         |
| Dispositivos          | Pixel 3, 3a, 4, 4a, 5 y 5a; teléfonos de socios como Sharp; Android TV |
| Cómo se obtenía       | Por OTA con Android Beta, o flasheando                                 |
| Estabilidad de la API | Sí, desde la Beta 4                                                    |

La build no sumó API, solo correcciones y optimizaciones sobre lo congelado
en la Beta 4. El Pixel 5a con 5G se sumó a los dispositivos compatibles.
Google señaló las nuevas comprobaciones lint de Android Studio Arctic Fox
para splash screens propias, la ubicación aproximada pedida junto a la
precisa, los formatos multimedia y el permiso de muestreo alto de sensores.

Google publicó el código en AOSP el 4 de octubre de 2021, y el despliegue en
Pixel empezó el 19 de octubre.
